# A2.1 Yaqoot: review kit for the Claudex loop

## What is in this folder
- `PLAN.md`: the review plan the loop works from.
- `PROMPT_FOR_CLAUDE_CODE.txt`: the text to paste into Claude Code.
- `inputs/`: the brief, the canvas template, the full rubric, the teacher's posts, and the consolidated requirements.
- `submission/`: the final PDF, the Word file, the canvas slide, and plain-text copies for reading.

## Before you start
1. Claude Code is installed on your computer, with the claudex plugin.
2. The OpenAI Codex CLI is installed and signed in (`codex --version` works in a terminal).

## Steps
1. Unzip this folder.
2. Open a terminal in the folder and start Claude Code.
3. Paste the contents of `PROMPT_FOR_CLAUDE_CODE.txt`.
4. Read the findings. Approve only the edits you agree with.
5. Apply approved edits in the Word file, export to PDF, and check that the canvas page still matches the text.

## Notes
- The loop was built for software plans. Here it is used as a second reader, so treat its findings as suggestions.
- The canvas on page 2 of the report is a picture made from `submission/A2_1_Strategy_Canvas_Yaqoot_Mohammad_Alkhatib_261121.pptx`. If the wording of the canvas changes, edit the slide, export it as an image, and replace the picture in the Word file.
- The assignment allows two attempts. Uploading the current PDF first and resubmitting later is safe.
